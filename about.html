About TaskFlow

TaskFlow is a lightweight task-management web application built as part of the DevOps Fundamentals course. It demonstrates a complete CI/CD pipeline: containerized with Docker, built and pushed via GitHub Actions, and automatically deployed to Render.

Purpose

TaskFlow helps you capture, organize, and track day-to-day tasks with priorities, due dates, and completion status — all in a clean, simple interface.

Usage Guide

  1. Dashboard — See summary counts and quick links on the home page.
  2. Add Task — Use the form to create a task with a title, description, due date, and priority.
  3. Task List — Browse all tasks and filter by All / Pending / Completed.
  4. Task Detail — Open any task to view full details, mark it complete, or delete it.
  5. About / Help — You are here! Learn what the app does and how to use it.
